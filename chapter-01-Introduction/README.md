## 📝 How I Write These Notes

Each chapter follows the same format:

1. **What is it?** — Plain-English explanation
2. **How it works** — Step-by-step or conceptual breakdown
3. **Key terms** — A quick-reference table
4. **Hands-on notes** — What I tried, commands, screenshots
5. **KQL queries** — Useful queries with comments
